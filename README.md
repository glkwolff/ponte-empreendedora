# Ponte Empreendedora

Formulário passo a passo, em português e espanhol, que ajuda mulheres migrantes a montar o plano do seu negócio: perfil, clientes, calculadora de preço, organização do dinheiro, divulgação, matriz SWOT, metas e próximos passos.

É uma página estática (`index.html`), sem servidor nem dependências. As respostas ficam salvas apenas no navegador de quem usa.
